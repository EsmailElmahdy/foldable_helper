# foldable_device example

The full walkthrough, with screenshots from the iPhone Duo simulator, the demo video, and the
complete `pubspec.yaml`, `lib/main.dart` and `lib/home_screen.dart`, is in
[example.md](example.md). It's also on the
[pub.dev Example tab](https://pub.dev/packages/foldable_device/example).

```sh
cd example
flutter run   # iPhone Duo simulator (iOS 27.1) or an Android foldable emulator
```
